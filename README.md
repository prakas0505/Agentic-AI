# Agentic-AI
Agentic AI refers to AI systems that can work toward a goal by planning steps, using tools, observing results, and adjusting their actions with limited human intervention.

Unlike a traditional chatbot that mainly responds to prompts, an AI agent can perform a sequence of tasks to achieve an objective.
core components of an AI agent
- LLM (Large Language Model): Interprets instructions and supports reasoning.
- Planning: Breaks a complex goal into smaller tasks.
- Tools: Executes actions through Python, APIs, databases, or other software.
- Memory: Retains relevant information within a task or across sessions.
- Perception: Processes observations such as text, images, sensor readings, or datasets.
- Feedback loop: Evaluates results and decides what to do next.
- Guardrails: Restrict unsafe actions and keep the agent within its permissions.
